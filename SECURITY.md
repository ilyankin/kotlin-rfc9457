# Security policy

## Supported versions

Security fixes are provided for the latest released version. Upgrade to the latest release before
reporting a vulnerability that is already fixed there.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ilyankin/kotlin-rfc9457/security/advisories/new).
Do not open a public issue with exploit details, credentials, signing material, or other sensitive
information.

Include the affected artifact and version, the impact, and the smallest reproducer you can share
safely. You will receive follow-up through the advisory.
